# Rules for a knowledge repository

A repository whose `AGENTS.md` says `Layout: knowledge (PARA).`: the wiki, the work knowledge. The
personal instructions still apply, and this repository's own rules win over these.

- Follow the repository's `AGENTS.md` and its checks (its validator and pre-commit hook); a write
  that breaks one is fixed before the turn ends.
- PARA: `00-inbox/` for unsorted, `10-projects/` for work with an end, `20-areas/` and
  `30-resources/` for what is true now, `40-archive/` for finished work.
- Decisions and events are dated notes (`YYYY-MM-DD-slug.md`, `type: decision` or `type: event`)
  in the area or project they concern; there is no timeline folder.
- Each fact keeps one home; summaries link to detail instead of copying it.
- The wiki holds work only in general terms, with a pointer to the work knowledge repository.
