# Rules for a product repository

A repository inside the product-repos folder, shared with a team. The personal instructions still
apply, and this repository's own rules win over these.

- This repository belongs to a team. Follow its own `AGENTS.md`, `CONTRIBUTING`, templates and
  commit conventions over personal habits; when they conflict, the repository wins.
- Add nothing about personal workflow to it: no agent notes, research, plans, decision logs or
  skills. Knowledge about it goes to the work knowledge repository (`10-projects/` for work under
  way, `20-areas/` or `30-resources/` for what is true now), through distilling or a hand-off.
- Changes reach it only through a pull request; never push to its default branch.
- Work identifiers stay in work places: never copy names, links or content from here into the
  wiki or any public repository.
