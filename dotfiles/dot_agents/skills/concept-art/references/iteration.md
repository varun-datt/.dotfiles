# Iteration

Change **one** dimension per regeneration; don't stack three new clauses.

| If the result is… | Change only… |
|---|---|
| Wrong vibe | Style anchor |
| Too generic | Composition / camera / layout |
| Cluttered | Remove elements; add negative space |
| Off-brand color | Hex palette |
| Wrong text | Re-quote the exact string + "no extra characters" |
| Too literal | Shift to a structural or symbolic template |

Save each regeneration under a new filename so earlier candidates stay available for comparison.
