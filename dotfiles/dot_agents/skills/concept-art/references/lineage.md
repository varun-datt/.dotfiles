# Lineage

Patterns in this skill are adapted from community skills and remapped for Cursor's built-in image tool.

| Skill | Repo | What was adapted |
|---|---|---|
| pixeltamer | `gabelul/pixeltamer-gpt-image-skill` | Prompt structure, anti-patterns, self-verification, one-dimension iteration, style/context matrix |
| baoyu-article-illustrator | `jimliu/baoyu-skills` | Type × style × palette, zone templates, prompt files, color and text rules |
| baoyu-infographic | `jimliu/baoyu-skills` | Layout × style thinking, image-tool detection, no text patching, confirm-before-generate, sensitive-data stripping |
| canvas-design | `anthropics/skills` | Visual philosophy, subtle reference, minimal text as design |
| generating-images | `spencerpauly/awesome-cursor-skills` | Context gathering, sibling matching, wire-up after save |
| visual-explainer | `nicobailon/visual-explainer` | When to prefer HTML over raster; anti-slop aesthetics |

Presets: style sentences follow Google's Nano Banana and OpenAI's GPT Image prompting guides (one named style, quoted text, positive phrasing). Palettes draw on IBM Carbon, Okabe-Ito, and Catppuccin Latte/Mocha, with violet hues removed and every ink/background pair checked at 7:1 or higher.
