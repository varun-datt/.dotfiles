# Larkspur Freight work knowledge

PARA layout: `00-inbox`, `10-projects`, `20-areas/<area>`, `30-resources`, `40-archive`.
Areas: routing, dock-scheduling, billing, platform, environments.
Decisions and events are named `YYYY-MM-DD-slug.md` and carry `type: decision` or `type: event`.
Runbooks quote the exact alert or error text near the top so search finds them.
