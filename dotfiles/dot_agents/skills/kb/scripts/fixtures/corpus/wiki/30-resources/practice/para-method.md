# PARA method

Four top-level folders, ordered by how actionable their content is:
- **Projects** (`10-projects`): a goal with a deadline.
- **Areas** (`20-areas`): ongoing responsibilities with a standard to keep and no end date.
- **Resources** (`30-resources`): topics of interest and reference material.
- **Archive** (`40-archive`): anything inactive from the other three.

Plus `00-inbox` for capture and `meta` for notes about the system itself.

Rules I follow
- File a note by where it will be *used*, not by topic.
- When a project ends, move its folder to the archive whole.
- Empty the inbox weekly.
